## 🧠 Lessons from production

<details>
<summary>Open the production incident checklist</summary>

- Test time zones. Add more tests for daylight-saving time changes.
- Make retries idempotent. One failed request must not create duplicate results.
- Test older smart TV browsers. Support in Chrome does not guarantee support on a 2018 TV.
- Make every AI answer traceable to its inputs. Without that link, it is a demo, not a system.
- Add useful logs before the next incident.

</details>
